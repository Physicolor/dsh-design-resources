## 4. 一处会误导人的旧副本

`%DSH_HOME%/profiles/node_modules/@deepseek-ai/dsh-client-ui-primitives/lib` 是**旧版**（只有 24 个 CSS 模块，没有 `SegmentedControl` / `MenuGroup` / `SegmentedTabs` / `TextShimmer` / `SettingsForm` / `Checkbox`）。产品实际加载的是 `app.asar` 里那份新版。

**判定「官方有没有某个控件 / 字号 / 几何」必须查 `app.asar` 或官方公开仓库**；只看 profiles 那份会得出与事实相反的答案。这条复核在 2026-10-02 推翻了一条旧结论（「官方没有 SegmentedControl」），并把 10 个此前记作「本仓库补充」的组件收回「产品里真实存在」——依据逐条记在 `components/origins.json` 的 `scenes` 字段。

## 5. 五种来源标记

正文里的每个数字都要带其中一种；没有标记的数值按铁律视为缺陷。

| 标记 | 含义 |
| --- | --- |
| `[官方源码]` | 官方仓库里的规则、令牌或组件实现（附文件路径或 URL） |
| `[运行时实测]` | 在本机运行中的 Harness 上采集，方法可复现（附快照或脚本） |
| `[外部指南借鉴]` | Apple / 华为官方指南里可迁移的判断方式；只借原则，不搬平台数值 |
| `[本仓库建议]` | 官方没有明文，本仓库给的取值与理由 |
| `[已知偏差]` | 官方界面自身互相矛盾、或与官方规则不符之处：记录在案，不当最佳实践 |

公开仓库里可迁移的规则清单与「只对官方内部成立」的约束清单见 `guides/01-official-basis.md`。
