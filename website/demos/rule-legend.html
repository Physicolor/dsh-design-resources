MF强制
不满足即判为缺陷，审核可拒 → 必须修改或给出书面例外理由。
例：CT-MF-01 Button 计算高度只允许 36 或 28。
RC推荐
默认照做；偏离需在插件 README 说明理由 → 不阻塞合并，但记录在案。
例：TK-RC-13 不得引入档位外的字号。
AD建议
供取舍参考，允许按场景判断 → 无需说明。

冲突时官方优先

本规范约束的是新写的界面与插件之间的协调，不是推翻产品自身的既有实现；为了对齐规范去覆盖官方控件，恰恰违反 CT-MF-12

官方控件自带的过渡沿用官方值 · Switch 滑块是官方 120ms ease，不在五档之内
官方控件未提供的状态不自行补样式 · Switch 没有 hover 态、Pill 没有 active 态
控件内部间距不套用控件间距建议 · Button 文本与图标之间是官方 gap 4px
