Stepper 数字步进器

外壳沿用官方 Input 的 .wrap（32px / 0.5px border-l4 / r8 / bg-layer-1），按钮三态沿用官方 Button 的 .ghost 与 :disabled（opacity .4），图标容器 16×16。官方没有此控件，其余数值为 § 本仓库建议值，见 README。

默认：中间值（两侧按钮都可用）

值 3，范围 0–10。数字用 tabular-nums 等宽渲染，加减时读数不横向跳动。

到下界：减号按钮 disabled

到达 min 后按钮是真的 disabled（opacity 0.4 + cursor: not-allowed），点击与 Tab 都被拦住。

到上界：加号按钮 disabled

到达 max 后加号按钮同理禁用。

整组 disabled

整组禁用时数字降为 label-tertiary（不靠整体降透明度，CT-MF-09），两个按钮走官方 Button 的 :disabled。

小数值（step = 0.5）

step 可以是小数；加减时按 step 与当前值中更细的小数位取整，避免 0.1 + 0.2 的浮点尾巴。

与外部 label 配合（id 落在数字输入框上）

外部 label 用 for 指向输入框（组件的 id prop）；此时屏幕阅读器以 label 为准，aria-label 作为兜底。

状态静态展示（hover / active / focus，演示用强制类）

左：hover 底色 interactive-bg-hover；中：输入框 2px 焦点环；右：active 底色 interactive-bg-active。真实运行时把鼠标移到按钮上、或用 Tab 走一遍即可看到同样的三种状态。

本页是纯静态外观演示，不含 React 逻辑：加减、键盘 ↑/↓、手输提交等行为请看 index.tsx。
