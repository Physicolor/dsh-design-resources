# Stepper 数字步进器

生成几张图片、重试几次——对话框里那个「减号 数字 加号」的三件套。用户点一次走一格，也能直接在数字上把值打进去。

## 什么时候用它

- 有明确上下界、按固定步长变化的数字：生成数量、份数、重试次数。
- 需要精确停在某一格，键盘上下键比拖动更可控时，比如端口号、页码。
- 表单里已经有上下界的约定，希望用户根本走不出界，而不是填完再报错。

## 什么时候不要用它

- 范围很大或压根没有边界（音量、进度、任意金额）：请改用滑杆或普通输入框，一格一格点太慢。
- 需要一次性输入一长串数字：用普通输入框，步进器每点一次只走一格。
- 候选值是有限的固定集合：请改用分段控件或下拉，不要让用户靠加减去凑。
- 布尔开关：请改用开关。
- 只给看不给改：不要用步进器。它会告诉读屏用户「这里可以用键盘改值」，做不到就是撒谎。

| 场合 | 用哪一个 |
| --- | --- |
| 有上下界，按固定步长一点点变 | 步进器 |
| 范围很大或没有边界 | 滑杆 |
| 要一次输一整串数字 | 普通输入框 |
| 候选值是固定的几项 | 分段控件或下拉 |
| 只有开和关 | 开关 |

## 怎么用得好

**先让用户知道自己在改哪个值。** 步进器自己不说明它管的是什么，旁边那行标签才是重点。几个步进器叠在一起却不写标签，用户只能靠位置猜。

**到了边界就停住。** 到达上下界时把对应的那一侧变灰，比让用户反复点一个没反应的按钮诚实得多。

**数字要显示出来。** 减号和加号之间那个数字就是全部反馈；把它藏起来或者只留一个占位符，用户点完不知道自己点到了哪里。

**小心手输带来的意外。** 直接打字是最快的路径，但也最容易越界或留空。放得进界内就立刻生效，放不进就在用户离开时收回到边界。

**别指望长按连加。** 按住不放不会连续变化。需要跨很大区间时，用户更愿意直接打字，所以手输这条路要留着。

**点完之后，读屏用户听不到新值。** 数值变的是中间那一格，焦点还在按钮上。这个值本身重要的时候，在外面多给一个会播报当前值的区域。
