# Pill 胶囊

打开数据面板，顶部一排「今天 / 最近 7 天 / 最近 30 天」，点哪一段图表就换哪一段——这一排小胶囊就是它。会话列表顶上的「全部 / 未读」也是它。

## 什么时候用它

- 一组互斥的筛选条件里挑一个：时间区间、状态分类、只看本会话。
- 短状态可以直接点着切换的时候，比如在「进行中 / 已完成」之间来回点。
- 一屏里要塞下一整排选择，而每个选项又只有两三个字。

## 什么时候不要用它

- 点下去要发生一件事（保存、删除、重试）：请改用按钮。胶囊说的是「选中了哪一个」，不是「执行一件事」。
- 只标一个状态、点不动：请改用标签。给静态胶囊加点击，用户会以为一切都能点。
- 开和关：请改用开关。开关有明确的开与关，胶囊表达的是「一组里挑中了这个」。
- 同一组里要同时选中好几个：胶囊一次只表达一个选中项，多选场景它担不起来，请改用复选框组。
- 想用胶囊的颜色表达「成功 / 失败」：那是标签的活；胶囊的选中色只说明被选中，不说明好坏。

| 场合 | 用哪一个 |
| --- | --- |
| 点一下就执行一件事 | 按钮 |
| 一组互斥条件里挑一个，选完界面立刻变 | 胶囊 |
| 只标状态，点不动 | 标签 |
| 开和关 | 开关 |

## 怎么用得好

**选中不能只靠颜色。** 选中状态除了换底色，还叠了一圈内描边，深浅主题下都能看出是「这一枚被选中了」。把界面转成灰度再确认一次——只剩深浅差别的选中态，色觉障碍用户读不出来。

**让它自己会说话。** 「全部」「未读」能独立读懂，「更多」在筛选条里就读不懂了。一排放四五个胶囊时，用户扫的是字，不是位置。

**能点的和不能点的长得一样会出事。** 决定这排胶囊能点之后，整排都要能点；混一枚点不动的进去，用户会连点两三下才反应过来。

**别把长句子塞进胶囊。** 胶囊刻意做得比按钮小、比按钮安静，文案一长就会横着撑开整行。超过四五个字就该换成别的控件，或者把长的那一项挪进菜单。

**键盘用户要看得见自己走到哪了。** 能点的胶囊是真的按钮，Tab 走到它身上时要给一个可见的焦点环；没有的话键盘用户在整排里完全失去位置感。
