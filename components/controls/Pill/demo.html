Pill 胶囊

几何来自官方 Pill.module.css（h24 / pad 0 8px / gap 4px / r12 / 12-18；选中态换成 ghost-active 底 + 1px 内描边）。实现为本仓库原创。

有 onClick → <button type="button">（可点击，鼠标移上去看 hover 底色）

三枚胶囊是一个单选组：左为未选中、中为选中（active）、右为未选中。

静态态：hover 与键盘焦点

左：鼠标悬停时的底色（interactive:hover）。右：Tab 聚焦时的焦点环（§ 本仓库建议值，官方 Pill 未定义）。

没有 onClick → <span>（只读，不可点击）

只读胶囊没有 pointer 光标和 hover 反馈，用来展示不属于当前筛选维度的信息。
