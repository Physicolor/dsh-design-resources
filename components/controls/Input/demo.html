Input 输入框

几何来自官方 Input.module.css（h32 / pad 0 8px / gap 6px / r8 / 0.5px 描边；图标容器 16×16；14-22）。实现为本仓库原创。

基础

默认状态：0.5px 描边 border-l4，底色 bg-layer-1，占位文字 label-dimmed。点进去能看到边框变成 brand-primary。

带 16×16 前置图标（间距 6px）

图标容器 16×16，颜色 label-tertiary；图标本身应 aria-hidden，名字由输入框自己的 label 提供。

聚焦态（:focus-within 时边框换成 brand-primary）

左为静态展示的聚焦描边；右侧可以直接点进去，看到同一个效果。

禁用（§ 本仓库建议值：官方没有 disabled 视觉）

opacity 0.4 沿用官方 Button 的禁用读法，让「不能用」在全库是同一个强度。

宽度由外层 className 控制

组件本身是 inline-flex，宽度交给调用方；下面两个输入框同高不同宽。

提示：真实组件把 ref 和全部 input 属性透传给内部原生 <input>；本页直接用原生标签静态展示。
