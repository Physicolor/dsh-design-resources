SegmentedControl 分段控件

容器内边距取自官方 Menu 的 .list（4px / gap 0），外层圆角取自官方 Pill（r12），段高与内边距取自官方 Button 的 md 36px / sm 28px 两组，选中段直接复用官方 Pill .active 的填充与内描边。官方没有此控件，段圆角等为 § 本仓库建议值，见 README。

md（段高 36px）· 三段，第一段选中

选中段：label-primary 文字 + ghost-active-fill 填充 + inset 1px 描边；未选中段：label-secondary 文字、透明底。

sm（段高 28px）· 三段，第二段选中

sm 组：段高 28px、字号 12/18、段内边距 0 10px（官方 Button .sm）；容器内边距与外圆角不变。

带图标（图标容器 16×16，图标 aria-hidden）

图标与文字间距 4px（官方 Button .button 的 gap）；图标是装饰，名称只来自文字，绝不能只给图标。

整组禁用

文字降为 label-tertiary（CT-MF-09：不靠整体降透明度），选中段填充保留，仍能读出「当前是哪一段」；按钮为原生 disabled。

状态静态展示（hover / active / 焦点环，演示用强制类）

hover / active 底色为官方 interactive-bg-hover / interactive-bg-active（只作用于未选中段）；焦点环为 2px 品牌色 + 2px 外偏移（§ 建议值）。真实运行时用鼠标与 Tab 键即可复现。

无选中项（value 不在 options 里）

没有任何一段点亮；组件把第一段作为 Tab 落点（roving tabindex 的兜底），键盘不会整组跳过。

本页是纯静态外观演示，不含 React 逻辑：方向键切换、onChange 回调等行为请看 index.tsx。
