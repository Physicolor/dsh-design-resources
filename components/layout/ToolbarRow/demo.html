ToolbarRow 工具条行

行高 32px 取自官方 ConnectionIndicator .indicator；间距 4px 取自官方 Button .button 的 gap；filled 形态用官方 Button .toolbar 的底色。内边距与 flex-wrap 为本仓库建议值。

md（32px）· plain 透明底 + 底部 hairline

sm（28px）· 与 Button size="sm" 等高

filled 形态 · 浮在深色内容之上

sticky 吸顶（在下面的框里滚动看看）

向下滚动，工具条会停在框的顶部，底部 hairline 把它和内容分开。
