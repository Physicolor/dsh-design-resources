# SettingsRow 设置项行

> 官方没有这个组件。下面是本仓库为插件作者准备的实现建议——它能用、数值逐条锚定官方既有选择器，但产品里并没有这个界面。

用户打开设置，想关掉「自动保存」。他得先找到那一条、读懂它是干什么的，再找到右边的开关——三件事要在同一行里完成。

左边是标题，下面可以跟一句解释；右边是控件；行与行之间一条浅线。点标题文字也能操作控件。

## 什么时候用它

- 设置面板里「一个开关管一件事」的行。
- 需要标题加一行解释的设置项。
- 一边是标签、另一边是输入框或下拉的表单行。
- 一组同类设置要排成一列，行与行之间需要一条看得见的分隔。

## 什么时候不要用它

- 侧边栏或导航里可点选的行。那是侧边栏行，它是按钮，带选中语义。
- 标签在上、输入在下的多字段表单。那是常规表单布局，这一行是左右分栏。
- 一行里塞好几个互不相关的控件。那说明这是两件事，拆成两行。
- 点整行是「跳到别处」。那是侧边栏行的活；设置项行表达的是「改一个值」。
- 需要用户填一长段内容。右边留给控件的宽度有限，长文本换行会把行撑得很高。

## 怎么用得好

**一行只放一个控件。** 这一行的标题是个标签，只会关联到行内的第一个控件。放两个，第二个就没有名字了，读屏用户听到的是个孤立的开关。

**标题是标签，不要另起一个标题层级。** 它比正文重一点就够了；整块设置区要不要有标题，那是外面的事。

**解释放补充信息，不放关键信息。** 它颜色更浅、字号更小，用户很可能一眼扫过去。操作之前就得知道的事，请写进标题。

**标签和控件之间留出呼吸。** 挨得太近，长标题的行会糊成一片，用户分不清哪句话说的是哪个控件。

**悬停要看得出来指向整行。** 这一行整行可点，鼠标移上去要有反馈，否则用户以为只有右边那个开关能点。

**被禁用的设置要说清原因。** 光把它调浅不够，用户不知道是自己没权限、还是条件没满足。

**最后一行不要再画线。** 分割线是用来分组的，末尾多出一条，会显得下面还有内容没显示。

| 这一行的用途 | 用哪一种 |
| --- | --- |
| 改一个开关，或填一个值 | 它 |
| 在一组里选一条 | 侧边栏行 |
| 跳到别处 | 侧边栏行或链接 |
| 标签在上、输入在下的表单 | 常规表单布局 |
| 一行里两件不相关的事 | 拆成两行 |
