# PanelHeader 面板标题栏

> 官方没有这个组件。下面是本仓库为插件作者准备的实现建议——它能用、数值逐条锚定官方既有选择器，但产品里并没有这个界面。

用户点开右侧的「文件」面板，第一眼要能回答三件事：这是什么、现在什么状态、怎么关掉。横在面板顶部的那一条，就负责这件事。

左边一个标题，下面可以再跟一句说明；右边留给动作；底下一条细线，把它和面板内容分开。

## 什么时候用它

- 可关闭的面板、抽屉、侧栏、浮层的顶部标题区。
- 需要在标题右边放「关闭、更多、折叠」这类动作时。
- 面板内部还要分段，需要一条和别处一致的细分割线时。
- 标题下面要补一句状态说明：改动了几个文件、属于哪个环境、上一次同步是什么时候。

## 什么时候不要用它

- 对话框的标题。对话框有自己成套的标题规格，字号更大、间距也不同，不要拿这一条顶上去。
- 页面级大标题或导航栏。那是另一个字号体系，这一条固定的是面板一级的字号。
- 只想放一条分割线。直接画一条线就好，不必为它套一层标题栏。
- 需要跟着滚动吸顶的整条工具条。那是工具条行，它支持吸顶。
- 标题本身要能点开或收起。那是折叠控件的活，这条标题栏不带任何交互。

## 怎么用得好

**一块面板只留一条。** 面板里再插一条同款标题栏，用户会以为出现了第二个面板。分段请用更轻的分节标题，不要复用这一条。

**标题只放名词短语。** 「会话设置」可以，「点击这里可以设置你的会话」不行。标题是路标，不是句子。

**右边的动作按重要性排。** 最常用的放在最靠近标题的位置，危险动作（删除、重置）放最右，并且跟别的动作拉开距离。一排图标按钮彼此不留缝，用户很容易点错。

**说明文字是补充，不是正文。** 它颜色更浅、字号更小，放「有几个文件已修改」这类可以略过的信息。用户不看它，也能把操作做完。

**标题长了要截断，不要换行。** 标题栏的高度是固定的，换行会把右边那排动作挤走。截断只影响视觉，读屏用户仍然能读到完整标题。

**仅图标的动作要说清自己是什么。** 一个叉、一个省略号，读屏用户听到的是一片空白，得由名字补上。

| 什么场合 | 用哪一条 |
| --- | --- |
| 面板、抽屉、侧栏的顶部 | 它 |
| 对话框顶部 | 对话框自带的标题区 |
| 页面顶部 | 页面标题或导航栏 |
| 面板内部分段 | 分节标题 |
| 跟着滚动吸顶的一排动作 | 工具条行 |
