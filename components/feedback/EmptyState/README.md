# EmptyState 空状态

列表、面板、搜索结果为空时，用它告诉用户「为什么空」以及「下一步做什么」。

## 是什么

一个垂直居中的块：`图标? + 标题 + 说明? + 动作?`。全部居中，宽度收紧到 280px 以内。
零依赖，只用到 `react` 和 CSS Modules。

| 插槽 | 排版 | 缺省行为 |
| --- | --- | --- |
| `icon` | 32×32 图标位，颜色 `--dsw-alias-label-tertiary` | 不传则不渲染整个图标位 |
| `title` | 14/22，`--dsw-alias-label-primary`，字重 500 | 必填 |
| `description` | 13/20（`--dsw-font-xs-13`），`--dsw-alias-label-secondary` | 不传则不渲染 |
| `action` | 16px 上方间距，横向居中 | 不传则不渲染 |

## 什么时候用

- 列表 / 面板第一次打开时什么都没有（首次使用）。
- 筛选、搜索之后没有匹配结果——这类文案要说明「是筛选条件导致的」，并给一个「清除筛选」的动作。
- 出错了但页面结构还在，用空状态 + 一个重试按钮承载。
- 功能被权限 / 配额挡住：说明原因和恢复方式。

## 什么时候不要用

- 数据还在加载：用骨架屏或 `LoadingDots`。把「还没加载」画成「空」会误导用户以为数据没了。
- 已经有内容、只是某一区块为空：先考虑这一块是否该整个隐藏，空状态会占掉宝贵的垂直空间。
- 需要用户做两件以上互斥的事（上传 / 导入 / 新建）：那是引导页而不是空状态，动作插槽里塞三个按钮会失去焦点。
- 一句话就能说清的错误，直接放在原位置（例如 `InlineNotice`），不要铺一整屏。

## 几何来源

**官方没有 EmptyState 组件**，`@deepseek-ai/dsh-client-ui-primitives/lib/` 下没有任何同名文件。
下表左列全部是本仓库建议值；右列写的是「为什么是这个数」，其中直接沿用官方数值的部分单独标出来。

| 数值 | 出处 / 依据 |
| --- | --- |
| 标题 `14px / 22px`、`font-weight: 500` | 沿用官方合成 token 的层级：`--dsw-font-s-14` 即 `14px/22px`（官方 `Button` 的 `.button` 也是 14/22）。字重 500 取自官方 `Modal.module.css` 的 `.title`。 |
| 说明 `font: var(--dsw-font-xs-13)` | 官方合成 token `13px/20px`，本组件直接整条使用（含字体族）。 |
| `gap: 12px` | 建议值。4 的倍数；同族间距里 8px 太紧（图标与标题贴在一起）、16px 太散。 |
| 标题与说明之间 `margin-top: 6px` | 建议值。两者是同一段文案的两行，应当比 12px 的块间距更紧，取 flex `gap` 的一半节奏（`calc(-1 * 12px + 6px) = -6px` 抵消）。6 是 4 的倍数以外的值，这里刻意取，理由同上。 |
| 动作插槽 `margin-top: 16px` | 建议值。动作与文字是两个层级，间距应当明显大于块内间距（12px），取 16px。 |
| 图标位 `32×32` | 建议值。等于本仓库 `Button` 的 `md` 高度（36px）略小一档；32 是 4 的倍数，图标本身通常传 24–32px 的线稿。 |
| 图标颜色 `--dsw-alias-label-tertiary` | 建议值取色。空状态的图标是氛围而非信息，用三级文字色（官方 `.icon` 在多处用的就是这个 token，例如 `Input.module.css` / `Menu.module.css`）。 |
| `max-width: 280px` | 建议值。空状态文案通常 1–2 行；280px 在 14px 字号下约 20 个汉字一行，超过就该分两行了。 |
| `padding: 32px 12px` | 建议值，4 的倍数。空的容器需要呼吸感；左右 12px 是给「容器被压窄时文字不贴边」留的余量。 |
| `text-wrap: pretty` | 建议值。避免最后一行孤字（orphan），不支持的浏览器会忽略这条，无副作用。 |
| `justify-content: center` + `width: auto` | 建议值。注意：flex 列容器的子项是 shrink-to-fit，所以标题/说明在自然宽度不足 280px 时会收缩到内容宽度再居中，`max-width` 只是长文本的上限。**组件不会把文字拉满整行**。 |

实现为本仓库原创：几何用 `--dsh-empty-*` 变量承载，版式用 flex 列 + 负外边距微调，没有抄任何官方 CSS。

## 可访问性要点

- 图标位已经 `aria-hidden="true"`：图标只是氛围，语义由标题和说明承担，绝不会出现「只有一个图标没有任何文字」的空状态。
- 标题渲染成 `<p>` 而不是 `<h2>`：空状态常常出现在文章结构中间，硬塞一个标题层级会破坏页面的标题大纲。需要参与大纲时，调用方在空状态外面放自己的标题。
- **空状态必须说清「为什么空」**：「暂无数据」是没用的文案；「还没有会话，问第一个问题试试」才是。
- 空状态出现往往是因为一次操作（点了筛选、删了最后一条）。如果它是异步出现的，用 `role="status"` 包一层让屏幕阅读器知道内容变了（把 `role` 透传给根节点即可，组件会把其余属性展开到根 `<div>`）。
- 动作插槽里的按钮请只用 `primary` / `ghost`，并且**最多一个主操作**；三个并列按钮会让键盘用户难以判断该按哪个。
- 在深色 / 浅色两种主题下，`--dsw-alias-label-tertiary` 的对比度都可能低于正文标准，所以它只用在图标上；标题和说明分别用 `primary` / `secondary`，保证可读。
- 如果整个空状态只是视觉占位、内容完全由别处（例如一个 `aria-live` 区域）播报，请给根节点加 `aria-hidden="true"`，避免读两遍。
