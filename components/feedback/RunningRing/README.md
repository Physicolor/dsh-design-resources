# RunningRing 运行圆环

> 产品里有这个东西：左栏会话正在跑的时候，行首那枚会转的小环就是它。官方 primitives 包里没有这个组件（包里给「进行中」的是另一套像素追逐方块），所以数值是从运行中的界面直接采下来的——真值见 SPEC。

一条灰环，一小段弧绕着它跑，边跑边伸缩，一圈 1.5 秒。

它的意思只有一句：**这件事还在进行，还不知道要多久**。不是「完成了多少」（那是进度条的事），也不是「做完了」（那是状态点）。

## 什么时候用它

- 一条列表行的状态是「正在跑」：会话行的行首、任务行的左侧。
- 空间很小的地方——14px 就能说清一件事，不占一行，也不需要文案。
- 等待时长估不出来的时候：能估出来就该换成进度条。

## 什么时候不要用它

- 知道还剩多久。用进度条。转圈只回答「在动吗」，回答不了「还要多久」；HIG 的原话是能确定时长就优先给确定式的进度指示。
- 几毫秒就好的动作。闪一下反而像卡了。等超过约一秒再出现。
- 表达「完成 / 失败 / 警告」。那是静态状态点（`StateDot`）或标签，环转完就消失，停在那里只会被读成「卡住了」。
- 给按钮当加载图标。按钮自己该有 loading 态（文字变「发送中…」或按钮内换字形），不要在按钮旁边再挂一个环。
- 一屏挂好几个。一屏一个「正在跑」是状态，一屏五个是噪声。

## 怎么用得好

**旁边要有能读的东西。** 环本身对读屏是隐藏的：用 `label` 给一段视觉隐藏的「进行中」，或者让所在的行本身写明是哪件事。

**别把它停成一个整圆。** 减动效模式下它会停下来，但停在「还差一截」的那一帧——停成整圆，读起来就是「完成了」。

**颜色让它退后。** 产品用的是三级文字色。别染成品牌蓝：一蓝就变成「可点的东西」，而它不可点。

**时长别改。** 1.5 秒转一圈 + 1.5 秒伸缩是产品的档位，`spec/40-motion.md` 里记着；随便改成 0.8 秒，整个界面里两种转圈速度并存，一眼就看得出不是一个产品。

| 场合 | 用什么 |
| --- | --- |
| 正在进行、时长不可估 | 运行圆环 |
| 正在进行、进度可算 | 进度条 |
| 已经完成 / 失败 / 警告 | 静态状态点或标签 |
| 短暂等待（< 1 秒） | 什么都不用 |

实现细节见 SPEC.md。
