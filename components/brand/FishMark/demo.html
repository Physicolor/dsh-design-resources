FishMark 鱼标

几何来自官方 lib/index.js 的 FishLogo 区块（viewBox 0 0 23.16 17.04 · 默认宽 24 · 高 = 24 × 17.04 / 23.16）。实现为本仓库原创；路径数据与 icons/brand/fish.svg 逐字一致。

三档宽度：24 / 32 / 48（高度按官方比例 17.04 / 23.16 等比换算）

24px 宽 / 高 17.658 32px 宽 / 高 23.544 48px 宽 / 高 35.316

宽度是 size，高度是 size × 17.04 / 23.16（24 → 17.6580310880829），刻意保留小数，不凑整，所以三档都是同一只没被压扁的鱼。

跟随文字颜色（path 的 fill 是 currentColor）

label-primary label-secondary label-tertiary link state-success-primary

组件不给鱼标单独设颜色：path 是 fill="currentColor"，外层 color 换成哪个语义 token，鱼就跟着变，深浅主题自动跟随。

深色主题下（同一份标记，只换继承到的 token）

深色块里 label-primary 解析为 --dsw-static-neutral-bluish-50（近白），鱼标自动变白，不需要第二份图。

深色块只覆盖 --dsw-alias-bg-base 与 --dsw-alias-label-primary 两条，数值逐字取自 website/css/dsh-tokens.css 的 body[data-ds-dark-theme] 段。

作为独立图形被读出（title → role="img" + <title>）

这个鱼标在无障碍树里是有名字的图形（role="img"，名字 DeepSeek）
不传 title 就是默认形态：aria-hidden="true" 的纯装饰图形，屏幕阅读器完全跳过

并排布局（品牌条）

DeepSeek Harness

同排时靠 .mark 的两条 § 本仓库建议值：flex: none（不被压扁）与 vertical-align: middle（不贴着基线往下坠）。官方 FishLogo 没有配套 CSS，这两条不是官方数值。

提示：本页可直接双击在浏览器打开。颜色全部走 var(--dsw-*) token；把系统或宿主切到深色主题时，组件代码不需要改。
