# FishMark 鱼标

品牌条上那只鱼。启动页、关于页、加载态里，位置只够放一个图形的时候，它替产品说一句「这是 DeepSeek」。

它只有一层颜色，跟着旁边的文字走——你不需要为深浅两套主题各准备一份图。

## 什么时候用它

- 位置只够放一个图形：头像位、工具条上的品牌位、启动页正中。
- 需要一眼认出「这是 DeepSeek」，但不必写出名字。
- 想让图形跟着文字颜色变：外层换个颜色就够。
- 和字标搭配时，它负责图形，字标负责可读的名字。

## 什么时候不要用它

- 用户需要读出品牌名。用字标，或者直接写文字；鱼标里没有可读的字。
- 每个页面、每个面板角落都摆一个。用户早就知道自己开的是什么，那个位置不如留给有用的信息。
- 只是想要一个装饰方块。用骨架屏或者普通图标——鱼标的品牌意味太重，随手放会把整块区域的分量改掉。
- 想改多色、渐变、双色调。它只有一层颜色，做不到。
- 当功能图标放进按钮。按钮里的图形得自己画，还得带一句说明。
- 在一闪而过的画面里做品牌宣传。那一瞬间短到什么都传不出去，不如等用户真正开始用的时候再放。

## 怎么用得好

**品牌出现一次就够。** 同一只鱼在一屏里出现两遍，第一遍就不值钱了。

**让它跟着文字色。** 别给它写死颜色，深浅主题才会自动跟随。

**默认当它是装饰。** 读屏用户不需要听到它，除非它是那块地方唯一的品牌信息——只有那种情况下才给它一句名字。

**缩放用尺寸参数，不要拉伸。** 硬拉会让细细的笔画发虚，鱼鳍的尖角先糊。

**要能点的区域，把动作挂在真正的按钮或链接上。** 给图形挂一个点击，键盘用户就够不着了。

| 场合 | 品牌标识该不该出现 |
| --- | --- |
| 启动页、关于页 | 出现 |
| 文档页眉 | 出现一次 |
| 内容区的每个区块 | 不出现 |
| 常用工具条 | 只在没有别的东西交代身份时出现 |
| 装饰占位 | 不出现 |
