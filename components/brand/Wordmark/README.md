# Wordmark 字标

文档页眉那一行：一条鲸鱼、一串小写字母拼出的品牌名，右边跟一个写着 HARNESS 的小方块。需要一次把完整品牌写出来的地方，就是它。

它是一整块图形，不是文字。这句话决定了它什么时候该用、什么时候会出问题。

## 什么时候用它

- 首屏、关于页、导出图、文档的页眉页脚：需要完整写出品牌名。
- 需要官方那种「图形加文字」的固定组合。
- 位置偏窄、只要文字那一截，可以把前面的鲸鱼关掉。

## 什么时候不要用它

- 位置只够放一个图形。用鱼标。
- 用户需要读出品牌名。字标里没有真正的文字节点，读屏用户听不到那串字母。要可读就用真实文字，或者「可见文字加鱼标」。
- 当页面标题。字标没有文字层级，也不进文档大纲；标题该是真正的标题。
- 缩得很小。笔画会糊成一团，那种尺寸只用鱼标。
- 需要多色、渐变、描边。它只有一层颜色，加一个小方块的反色。
- 当水印铺满背景，或者每个面板角上都来一个。页眉已经说过一次，再说就是噪音。

## 怎么用得好

**品牌跟在内容后面，不要抢在它前面。** 用户是来干活的；留给品牌的位置越大，留给内容的位置就越小。

**一屏一次。** 页眉已经放过，页脚就不必再来一遍。

**小方块里的字色要单独管。** 那是唯一不跟着文字色走的部分——字标落在深色块、渐变或者图片上时，那串字母可能和底色糊在一起，得给它一个能对上的颜色。

**别整体反色。** 图形和小方块是两段配色，一起翻过来对比度就失控了；要换色就换指定的那一处。

**要可读，就别指望图形。** 不同读屏软件对图形名的支持并不一致，真正的品牌名还是用文字写出来最稳。

**缩放用尺寸参数。** 硬拉会同时糊掉文字笔画和小方块里的字母。

| 场合 | 用什么 |
| --- | --- |
| 需要完整品牌名 | 字标 |
| 位置只够一个图形 | 鱼标 |
| 需要被读出来 | 真实文字，或可见文字加鱼标 |
| 页面标题 | 真正的标题，配鱼标 |
| 很小的地方 | 只用鱼标 |
