StateDot 状态圆点

几何来自官方 StateDot.module.css（默认外径 10px / 光环 opacity 0.1 / 实心核 inset 20% / 8 个 2×2 方块跑 1s 追逐、逐格相差 125ms）。实现为本仓库原创。

五种状态 · 默认外径 10px

done 完成 warning 警告 ongoing 进行中 error 失败 idle 空闲

ongoing 的 8 个方块正在循环播放追逐动画（1s 一轮，每格 animation-delay 相差 125ms，负延迟把 8 格排成一个环）。

size 只改外径 · 16px（内圈仍按 20% 比例缩放）

16px done 16px ongoing 16px error 16px idle

正确用法：与文字同行（圆点自身 aria-hidden，状态由文字承担）

这两行圆点没有任何可读文本：组件硬编码 aria-hidden="true"，屏幕阅读器读不到状态；转灰度后 done 的绿与 idle 的灰也可能难分。请务必配文字说明结果。
