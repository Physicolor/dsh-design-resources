# DisclosureRow 可展开行

一行标题，点一下露出下面的详情，再点一下收回去。

文件改动摘要里写着「已修改文件 3 个」，你想知道是哪 3 个，就得点开这一行。设置页里写着「高级选项」的那一行，也是它。一次工具调用结束后，你想看看它到底传了什么参数，还是它。

它的位置很固定：藏在别处的内容，先在这里露出一行标题，用户想看的时候自己拉开。

## 什么时候用它

- 内容是**补充信息**，先收起来不占地方：逐文件明细、原始参数、高级选项、历史记录。
- 一屏里排了很多条同类信息，全部摊开会淹掉重点，让用户挑着看。
- 需要在一行里同时说清两件事：这里有东西可看，以及现在是开着还是关着。

## 什么时候不要用它

- 这段内容用户每次都要看。默认收起来，等于把必经的路藏进抽屉里，用户会找不到。
- 展开出来的是主线内容，不是补充说明。那就直接写成标题加正文，别让用户多点一次。
- 点它其实是想跳到别处。那是链接的活：展开是「就地看到更多」，跳转是「换一个地方」。
- 一组内容里同时只能看一个。可展开行可以一起开好几个，互斥切换请改用标签或分段控件。
- 只是为了省空间。窗口变窄时，正确的做法是把入口收进菜单，而不是把入口折叠掉。
- 一行里想塞下超过「图标 + 标题 + 一小句补充」的东西。它只有一行高，塞不下。

## 怎么用得好

**这一行很矮。** 它比常规按钮还矮，只有一排文字那么多。折叠状态下默认只有左边那个小图标能被点到，手指上去就得瞄准。做触摸为主的界面时，让整行都能点。

**标题要说清楚点开是什么。** 写「已修改文件」，不要写「详情」「更多」。用读屏的人只听到这一行和「已折叠」「已展开」，旁边的上下文全丢了。

**折叠时可以补一句当前值。** 比如在标题右边挂一句「3 个」。展开以后这句就消失——详情里已经有了，不必重复。

**悬停时图标会变成箭头。** 折叠着把鼠标移到整行上，左边的小图标淡出、箭头淡入，等于说一句「这里能点」。这只是给鼠标的提示，别让它成为唯一的线索：键盘和触摸用户看不到它。

**同时展开好几条是允许的。** 它不像标签页那样互斥。如果你需要的恰恰是「一次只看一条」，说明这里不该用它。

| 场景 | 用哪种点法 | 为什么 |
| --- | --- | --- |
| 鼠标为主，行排得很密 | 只让左边的小图标可点 | 视觉最干净，不会误触到行里别的东西 |
| 触摸操作，行与行挨得近 | 让整行可点 | 手指点小图标容易点空 |
| 一行里还挂着别的可点元素 | 只让图标可点 | 避免点开和点别的动作分不清 |

有一个取舍要说白：只让图标可点的话，那个图标的可点范围比常规按钮的目标范围小，只是靠着额外扩了一圈看不见的热区才勉强够用。行挨得越近，误触越多。拿不定主意时，选整行可点。
