# 70 提交前自检清单

- 适用对象：提交插件的作者（自查）与插件审核者（审核）。
- 效力：清单本身不新增效力，条目效力继承其所属文档。
- 本文的判据是否可自动检测：逐条标注。标注含义：自动＝可由脚本对源码／构建产物／渲染结果判定；半自动＝脚本给出候选，需人确认；人审＝无法自动化。

使用方式：全部条目均为二元（是／否）。「必选」组出现任一条为「否」即不得提交；「推荐」组为「否」需在 README 写明理由。

## C. 审核者备注

- A09、A10 是最高频违规项，也最容易自动化：统计每个 `list` 座位的占用者 order 集合，缺值（未声明而落默认 0）与重复值即可直接列出。
- A23、A24、A30、A34、A36、A40 可合并为一次静态扫描，建议作为插件 CI 的第一道门。
- 人审项集中在 A01–A04、A12、A14、A35、A38、A41、A51：脚本无法给出唯一答案，审核者需按对应文档口径逐条确认。
