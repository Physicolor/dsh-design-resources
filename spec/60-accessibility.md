# 60 可访问性

- 适用对象：所有含交互的插件 UI。
- 效力：以 MF 为主，个别条目为 RC。（无 AD 条目。）
- 本文的判据是否可自动检测：部分。命中区、对比度、aria 属性、焦点样式存在性可自动或半自动检测；灰度可区分性、键盘路径完整性需人工验证。

## 1. 来源与基准

[HIG] 是唯一提供官方尺寸表的来源：macOS 控件命中区默认 28×28pt、最小 20×20pt（这是 HIG 唯一的官方尺寸表）。DSH 官方 CSS 未公开命中区规则，但其 Button 默认 h36、`.sm` h28 与该表一致（`.sm` 恰为 28）。因此本规范采用 28 / 20 作为命中区判据。

对比度阈值同样来自 [HIG] 引用的 WCAG：17pt 及以下文本 4.5:1；18pt 或粗体 3:1。

## 2. 命中区

| 项目 | 数值 | 来源 |
| --- | --- | --- |
| 常规控件命中区 | 28×28 | [HIG] 默认值 |
| 最小命中区 | 20×20 | [HIG] 最小值 |
| 官方 Button | 36 高 | [DSH-CSS] |
| 官方 Button `.sm` | 28 高 | [DSH-CSS] |

- `AC-MF-01`：任何可交互元素的命中区（含 padding 或热区扩展）不得小于 20×20；常规控件目标 28×28。
- `AC-MF-02`：命中区与视觉尺寸可以不同。11px 的 Tag 若可点击，必须把热区扩展到 ≥20×20；纯标记 Tag 不得绑定点击（与 `CT-MF-04` 一致）。
- `AC-MF-03`：相邻命中区不得重叠。判定：相邻两个交互元素的中心距 ≥ 两者命中半径之和。
- `AC-MF-04`：包含图标按钮的容器行高必须 ≥28。16×16 视觉图标 + 28 命中区是常见组合；判定：工具行容器计算高度 <28 即违规（自动可测）。

## 3. 对比度与颜色

- `AC-MF-05`：字号 ≤17pt 的文本对比度 ≥4.5:1；字号 ≥18pt 或粗体文本对比度 ≥3:1。[HIG]（引 WCAG）
- `AC-MF-06`：非文本 UI 元素（图标、边界、开关轨道）的对比度建议 ≥3:1。此条来自 WCAG 非文本对比要求，非 [HIG] 明文；本仓库建议采用。[本仓库建议]
- `AC-MF-07`：颜色不得是唯一的信息载体。[HIG] 状态必须同时有文字、图标或形状差异。判定：把界面转灰度后，任意两个状态的差异仍可识别（截图检测 + 人工确认）。
- `AC-MF-08`：Increase Contrast 变体要求见 [HIG]（自定义色需 light + dark + Increase Contrast 三套）。在 DSH 中的执行方式是只用语义 token，使增强对比由宿主主题承担；禁止绕过 token（与 30-tokens.md 一致）。

[实测] 拿产品自己的语义色算了一遍（公式在演示里现算，不是查表）：浅色主题白底下，`--dsw-alias-label-primary` 约 18.9:1、`label-secondary` 约 5.8:1，都达标；**`label-tertiary` 约 3.7:1，低于 4.5:1**，而 13px 说明文字与 10px 状态标签用的正是它。这是产品既有实现，按 00-overview §4.1「官方优先」处理：**记录为已知偏差，不覆盖官方控件**。给插件作者的可执行结论：正文与说明优先取 `label-primary` / `label-secondary`；用 `label-tertiary` 时不要把关键信息只放在那里。

## 4. 焦点与键盘

- `AC-MF-09`：所有可交互元素必须可 Tab 到达，并可用 Enter 或 Space 触发；Tab 顺序与视觉顺序一致（WCAG 2.4.3）。
- `AC-MF-10`：焦点必须可见。禁止用 `outline: none` 移除焦点样式而不提供替代。判定（自动）：出现 `outline: none` / `outline: 0` 且同一选择器无替代焦点样式即违规。
- `AC-MF-11`：焦点环规格。DSH 未公开焦点环数值，无权威数值；本仓库建议：2px 实线，颜色 `--dsw-alias-brand-primary`，外偏移 2px，圆角随控件（r18 / r14）。理由：2px 在深色与浅色主题下均可辨识，且不改变控件几何。
- `AC-MF-12`：焦点环不得被容器 `overflow: hidden` 裁剪。若被裁剪，改用内偏移（inset）焦点样式。判定：Tab 到区域边界控件时焦点环完整可见（半自动）。
- `AC-MF-13`：键盘操作不得有唯一鼠标路径。禁用右键菜单、拖拽作为唯一交互方式；必须提供键盘等价操作。[本仓库建议]

## 5. 语义与缩放

- `AC-MF-14`：纯图标按钮必须有可访问名称（`aria-label` 或可见文字）；纯装饰图标必须 `aria-hidden`。
- `AC-MF-15`：字号必须响应系统或浏览器缩放放大。[OH] 判定：浏览器放大到 200% 时，文本不截断、不重叠、不被容器裁剪。
- `AC-MF-16`：功能不随空间变化，只改变可见量。[HIG] 窗口收窄时应收起或折叠（进菜单、进浮层），不得删除入口。与 `FL-RC-05`、`MO-*` 无关，属于结构要求。
- `AC-RC-17`：不得用固定 px 高度夹死文本容器；容器高度需容纳放大后的行高。[本仓库建议]

## 6. 可检测性对照

| 条目 | 检测方式 | 自动化程度 |
| --- | --- | --- |
| `AC-MF-01` `AC-MF-03` `AC-MF-04` | 渲染后测量元素盒模型 | 自动 |
| `AC-MF-05` `AC-MF-06` | 计算前景/背景色并求对比度 | 自动（需正确解析 token 实际值） |
| `AC-MF-07` | 灰度化截图对比 | 半自动 |
| `AC-MF-09` `AC-MF-13` | 键盘遍历脚本 | 半自动 |
| `AC-MF-10` `AC-MF-12` | 样式扫描 + 人工确认 | 半自动 |
| `AC-MF-14` `AC-MF-15` | 属性扫描 / 缩放渲染 | 自动与半自动 |
| `AC-MF-16` | 窄宽度截图检查入口是否消失 | 人工 |
