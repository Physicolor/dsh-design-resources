# 指南概览：先选位置，再设计界面

> 本指南帮助 DeepSeek Harness 插件作者判断界面该出现在哪里、能使用哪个公开扩展座位，再用真实产品文字和控件搭建内容。

## 读完这一页要能做什么

- 判断功能是全局偏好、完整设置分区，还是只影响当前任务／会话的选项。
- 当前视图的筛选、显示/隐藏与排序等临时操作，优先放在受影响的内容附近；跨会话偏好才进入全局设置。
- 区分左侧栏、对话区浮层和宿主右栏；不要把插件绘制的界面当成 DSH 原生 UI。
- 选择真实存在的控件，说明每种控件适合解决什么问题。
- 从本地实景截图和官方源码逐项核对页面示意。

## 按这个顺序决定

| 你的内容 | 先看 | 公开座位或结构 |
| --- | --- | --- |
| 一个全局偏好，例如语言、外观或对话行为 | [设置项放进通用设置](20-pattern-settings.md#通用设置里的一项偏好) | `settings.general.item` |
| 只影响当前视图的筛选、显示或排序 | 放在受影响内容附近；先核对该功能的公开座位 | 不要把临时视图状态写成全局 `settings.general.item` 偏好 |
| 一组需要单独成页的插件设置 | [在设置里增加分区](20-pattern-settings.md#需要独立的设置页时) | `settings.section`；页面仍由宿主设置窗口承载 |
| 当前会话的常驻辅助内容 | [会话区、浮层与右栏](21-pattern-sidebar-panel.md#会话区内的插件内容) | 按公开 API 选择 `conversation.*` 或 `rightbar.*` |
| 左栏的插件入口、工作区或设置入口旁操作 | [左侧栏的实际结构](21-pattern-sidebar-panel.md#左侧栏由哪些区域组成) | `sidebar.panellist`、`sidebar.workspaces`、`sidebar.footer.action` |
| 独立的插件设置窗口 | 先读 [设置页的边界](20-pattern-settings.md#独立插件窗口的边界) | 当前公开座位表没有专用的插件窗口座位，不自行假定存在 |

`dsh-widgets` 可以作为“插件内容与会话区关系紧密”的社区案例：它将自己的面板注册到 `conversation.input.overlay`，并把数据摘要放在 `conversation.composer.dock`。这些卡片是插件提供的，不是 DSH 默认组件；它也没有占用宿主 `rightbar`。详情见 [会话区、浮层与右栏](21-pattern-sidebar-panel.md#会话区内的插件内容)。

## 本指南讲什么、不讲什么

本指南说明 DSH 原生窗口的区域职责、公开扩展座位和产品里真实存在的控件。它不是一套品牌皮肤，也不以个人审美替代界面层级、区域关系和控件语义的判断。凡属于本仓库建议的部分，都会与官方源码或运行时观察分开标记。

## 截图与 HTML 的关系

运行中的 DSH 截图只用于逐项核对。审阅裁图保存在 docs/reference/review-crops/，不会作为图片嵌入生成的网站；网站上的 HTML 是可单独检查的结构示意。截图不能证明画面外的状态，示意也不能把社区插件内容说成宿主原生界面。逐项映射见 [演示核验记录](../docs/reference/demo-evidence.md)。

干净截图使用独立的 design-guide-clean profile，只加载 DeepSeek 官方 base、web-app 与 schedule bundle；不会关闭或改动用户正在使用的插件配置。完整会话截图可能含个人正文，因此只保留当前核对所需的局部裁图。宿主页签缺少干净全屏采集时，明确标成源码／用户参照核验，不冒称干净实景。

## 依据标记

| 标记 | 含义 |
| --- | --- |
| `[官方源码]` | DSH 官方源码、公开文档或公开座位表中的事实 |
| `[运行时实测]` | 在明确记录的 DSH profile 和版本中实测；不外推到其他版本或插件组合 |
| `[本仓库建议]` | 官方没有规定时给出的社区建议，不代表 DSH 承诺 |
| `[插件示例]` | 某个插件自己的界面或布局，只用来说明扩展关系 |
| `[待核对]` | 尚无干净实景或官方源码支持，暂不作为规范事实 |

## 建议阅读顺序

1. [先选扩展位置](10-principles.md)：看内容是否全局、是否常驻、是否只属于当前会话。
2. [设置页模式](20-pattern-settings.md)：对照通用设置项、设置分区和独立窗口边界。
3. [侧栏与面板扩展](21-pattern-sidebar-panel.md)：看左侧栏、对话区、浮层与右栏的差别。
4. [控件与布局元素](../components/index.json)：复用实际存在的按钮、开关、下拉选择和会话视图页签。
5. [座位选择与扩展集成](30-seats-integration.md)：把界面选择落实到 API、类型和共存约束。
6. [自检与来源](40-selfcheck-sources.md)：检查截图映射、来源和已知限制。
