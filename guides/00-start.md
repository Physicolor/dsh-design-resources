# 指南概览：先看一屏，再选区域，最后选座位

> 本指南帮助 DeepSeek Harness 插件作者先认清一屏是怎么构成的，再判断界面属于哪个区域、能使用哪个公开扩展座位，最后用真实产品文字和控件把内容搭起来。

## 读完这一页要能做什么

- 说出新建一个对话之后这一屏由哪几段组成，并分清哪些段官方给了座位、哪些没有。
- 判断功能是全局偏好、完整设置分区，还是只影响当前任务／会话的选项。
- 当前视图的筛选、显示/隐藏与排序等临时操作，优先放在受影响的内容附近；跨会话偏好才进入全局设置。
- 区分左侧栏、中栏对话区、中栏两侧留白带和宿主右栏；不要把插件绘制的界面当成 DSH 原生 UI。
- 选择真实存在的控件，说明每种控件适合解决什么问题。
- 从本地实景截图和官方源码逐项核对页面示意。

## 一屏由哪些部分组成

<!-- demo: frame-columns | 一屏区域地图：产品复刻按实测尺寸搭（左栏 280、中栏流动、右栏可开合），指针扫过哪一块就标出哪一块。逐段的座位归属见下表，完整版见 [区域地图](../spec/05-region-map.md)。 -->

DSH 的窗口是**三条各自全高的轨道**，没有横跨整个窗口的顶栏：左栏、中栏、右栏各有自己的头部。所以「这个按钮放哪」要先问属于哪一条轨道，再问在这条轨道的哪一段。

| 轨道 | 自上而下有哪几段 | 官方座位 | 能不能挂插件 |
| --- | --- | --- | --- |
| 左栏 | 品牌行 | 品牌标志与名称 | 宿主独占 |
| 左栏 | 全局面板入口（插件、自动化任务） | 面板图标列 | 可以追加 |
| 左栏 | 工作区与会话列表 | 整块归宿主；行内动作与「…」菜单可追加 | 部分可追加 |
| 左栏 | 底部：设置入口 + 扩展动作区 | 设置入口归宿主；旁边的动作区可追加 | 部分可追加 |
| 中栏 | 常驻导航头（没有会话时也在） | 全局导航在会话标题左侧 | 宿主独占 |
| 中栏 | 会话头：标题、标题旁动作、右上角工具行、最右角 | 三处都是公开座位，最右角**只能一个控件** | 可以追加 |
| 中栏 | 视图区（对话 / 轨迹 / 上下文那排页签） | 会话视图注册位，**一次只渲染一个** | 可以追加 |
| 中栏 | 输入卡与它上下的插入点 | 输入卡工具行、卡上方、卡下方、卡内浮层 | 可以追加 |
| 中栏 | **对话区左右两侧的留白带** | **没有座位** | 只能借道别的座位 |
| 右栏 | 打开后是一条独立轨道，不是浮层 | 轨道本体与会话内容区归宿主，页签内动作可追加 | 部分可追加 |

三处要点，读完这一页你应该记住它们：

1. **右栏是页面第 4 列，中栏两侧的留白带是居中之后剩下的余数。** 前者自己定宽、最窄也有 300px；后者可以缩到 0。这是它们唯一可靠的分界。
2. **中栏那排页签不是三个写死的页面。** 官方把它描述为「已注册的会话目标视图，一次渲染一个」，谁注册谁就多一个可切换的视图。
3. **官方没有座位的位置是存在的，而且不止一处。** 中栏两侧留白带、独立插件设置窗口、全局顶栏都属于这一类。这类位置要按社区约定使用，并在插件文档里写清「官方无此座位」。

逐段的细节、以及四处「官方没有座位」的位置清单，见 [区域地图](../spec/05-region-map.md)。中栏内部该占满还是该进页签，见 [中栏能不能单独使用](15-middle-column.md)。

## 按这个顺序决定

| 你的问题 | 先看 | 公开座位或结构 |
| --- | --- | --- |
| 我还不确定内容属于哪条轨道、哪一段 | [区域地图](../spec/05-region-map.md) | 先定区域，再谈座位 |
| 我想占中栏，但不确定该占满、进页签还是做浮层 | [中栏能不能单独使用](15-middle-column.md) | `conversation.view` 是页签机制；留白带没有座位 |
| 一个全局偏好，例如语言、外观或对话行为 | [设置项放进通用设置](20-pattern-settings.md#通用设置里的一项偏好) | `settings.general.item` |
| 只影响当前视图的筛选、显示或排序 | 放在受影响内容附近；先核对该功能的公开座位 | 不要把临时视图状态写成全局 `settings.general.item` 偏好 |
| 一组需要单独成页的插件设置 | [在设置里增加分区](20-pattern-settings.md#需要独立的设置页时) | `settings.section`；页面仍由宿主设置窗口承载 |
| 当前会话的常驻辅助内容 | [会话区、浮层与右栏](21-pattern-sidebar-panel.md#会话区内的插件内容) | 按公开 API 选择 `conversation.*` 或 `rightbar.*` |
| 左栏的插件入口、工作区或设置入口旁操作 | [左侧栏的实际结构](21-pattern-sidebar-panel.md#左侧栏由哪些区域组成) | `sidebar.panellist`、`sidebar.workspaces`、`sidebar.footer.action` |
| 官方没有座位，但我确实想放在那里 | [官方没有座位的位置](31-unofficial-regions.md) | 借道已有座位，并在 README 写明官方无此座位 |
| 独立的插件设置窗口 | 先读 [设置页的边界](20-pattern-settings.md#独立插件窗口的边界) | 当前公开座位表没有专用的插件窗口座位，不自行假定存在 |

`dsh-widgets` 可以作为「插件内容与会话区关系紧密」的社区案例：它把会话统计轨放在中栏右侧那条留白带上，借的座位是 `conversation.input.overlay`，面板开关在会话头右上角工具行，数据摘要在输入卡下方。这些卡片是插件提供的，不是 DSH 默认组件；它也没有占用宿主右栏。借道的完整纪律见 [官方没有座位的位置](31-unofficial-regions.md)。

## 本指南讲什么、不讲什么

本指南说明 DSH 原生窗口的区域职责、公开扩展座位、官方没有座位的位置，以及产品里真实存在的控件。它不是一套品牌皮肤，也不以个人审美替代界面层级、区域关系和控件语义的判断。凡属于本仓库建议的部分，都会与官方源码或运行时观察分开标记。

## 截图与 HTML 的关系

运行中的 DSH 截图只用于逐项核对。审阅裁图保存在 docs/reference/review-crops/，不会作为图片嵌入生成的网站；网站上的 HTML 是可单独检查的结构示意。截图不能证明画面外的状态，示意也不能把社区插件内容说成宿主原生界面。逐项映射见 [演示核验记录](../docs/reference/demo-evidence.md)。

干净截图使用独立的 design-guide-clean profile，只加载 DeepSeek 官方 base、web-app 与 schedule bundle；不会关闭或改动用户正在使用的插件配置。完整会话截图可能含个人正文，因此只保留当前核对所需的局部裁图。宿主页签缺少干净全屏采集时，明确标成源码／用户参照核验，不冒称干净实景。

## 依据标记

本仓库只有五种来源标记，任何数值必须携带其中一个。没有标签的数值即为缺陷：

| 标记 | 含义 |
| --- | --- |
| `[官方源码]` | DSH 官方源码、公开文档或公开座位表中的事实 |
| `[运行时实测]` | 在明确记录的 DSH profile 和版本中实测；不外推到其他版本或插件组合 |
| `[外部指南借鉴]` | 外部指南的条文，经本仓库转写后引用，不搬平台专属数值 |
| `[本仓库建议]` | 官方没有规定时给出的社区建议，不代表 DSH 承诺 |
| `[已知偏差]` | 官方实现与本规范冲突，或两处证据互相矛盾；记录，不覆盖官方 |

`spec/` 里较早的文档用的是另一套写法（`[DSH-CSS]` / `[实测]` / `[HIG]` / `[OH]` / `[本仓库建议]`），两套一一对应，不要在同一个文档里混用。对应关系见 [总览的 4.2 节](../spec/00-overview.md)。

另外还有一个不是来源标记的标注：`[插件示例]` 用来指出「这是某个插件自己的实现或布局」，只说明扩展关系，不构成任何数值的出处。

## 建议阅读顺序

1. [区域地图](../spec/05-region-map.md)：先知道这一屏由什么组成、哪些位置官方没给座位。
2. [中栏能不能单独使用](15-middle-column.md)：占满、进页签还是做浮层。
3. [先选扩展位置](10-principles.md)：看内容是否全局、是否常驻、是否只属于当前会话。
4. [设置页模式](20-pattern-settings.md)：对照通用设置项、设置分区和独立窗口边界。
5. [侧栏与面板扩展](21-pattern-sidebar-panel.md)：看左栏、中栏、浮层与右栏的差别。
6. [控件与布局元素](../components/index.json)：复用实际存在的按钮、开关、下拉选择和会话视图页签。
7. [座位选择与扩展集成](30-seats-integration.md)：把界面选择落实到 API、类型和共存约束。
8. [自检与来源](40-selfcheck-sources.md)：检查截图映射、来源和已知限制。
